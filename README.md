## قواعد التوسعة

- أضف صفحات العميل داخل `src/app/(store)/`، واترك `src/app/layout.tsx` محايدًا قدر الإمكان.
- ضع منطق كل ميزة وبياناتها ومكوناتها داخل `src/features/<feature>/`، مثل `catalog` ثم `cart` و`checkout` لاحقًا. لا تنشئ مجلدًا لميزة قبل الحاجة إليها.
- ضع المكونات التي تستخدمها أكثر من ميزة في `src/components/ui/`، ومكونات الترويسة والتذييل في `src/components/layout/`.
- غيّر روابط المتجر في `src/config/site.ts` بدل تكرارها داخل المكونات.
- بيانات الأقسام الحالية ثابتة في `src/features/catalog/categories.ts`. عند ربط قاعدة بيانات أو CMS، استبدل مصدرها بطبقة بيانات/خدمة مع الحفاظ على نوع `Category` وواجهة المكونات قدر الإمكان.
- روابط بطاقات الأقسام والبحث تشير حاليًا إلى `/products?category=...` تمهيدًا لصفحة المنتجات؛ المسار غير منفّذ بعد.
